## 1. 宿主机硬件与系统基准

- **主板型号**：HP <主板型号> 主板（LGA1150 架构）；
- **当前 CPU**：Intel Pentium <CPU型号>（双核双线程，升级路径：已预定直换 <升级CPU>）；
- **内存规格**：DDR3 双通道 2 × 8GB（总计 16GB）；
- **操作系统**：Ubuntu 24.04 LTS (Kernel 6.8.0-138-generic)；
- **磁盘存储**：系统主盘 455GB（可用空间 ~390GB），外加定时冷备归档机制。

## 2. 网络拓扑与内外网双访问通道

```
[外部公网 / 移动端]
       │
       ▼ (Tailscale 虚拟私网)
 <你的机器名>.ts.net 
       │
       ├─────────────────────────────────────────┐
       ▼                                         ▼
[家庭内网核心: <内网IP备用>]              [导航中枢: Homarr :7575]
(关WiFi时走 .70 有线)                      (浏览器打 80 端口自动重定向)
       │
       ├── 8443 / 8444 : Monpanel 监控统一入口 (Let's Encrypt 证书自动续期)
       ├── 8083 / 8084 : Obsidian Web 知识库 (Docker)
       ├── 20128       : 10Router AI 网关 (Docker)
       ├── 20129       : TokenHub 代币看板 (Docker)
       ├── 20130       : Vaultwarden 账号台账 (Docker)
       ├── 8660        : YesPlayMusic 网易云高颜值播放器 (Docker)
       ├── 8090 / 8095 : Mars TV 云影院与爬虫蜘蛛 (Systemd)
       └── 8767 / 8769 : aiduMEM 记忆引擎与 Embedding 嵌入 (Systemd)
```

- **统一入口体验**：维护者在内网直打 IP 或域名 `<你的域名>`，在异地直接打开 Tailscale 即可穿透访问所有面板。
- **Homarr 分类与图标**：图标必须同源保存在本地 `media` 表（严禁引用外部 CDN，防止网络受阻导致白板）。

---

## 3. 运维生命周期与健康守护

- **无野跑进程**：所有长期服务一律托管为 Docker 容器（`restart: always`）或 Systemd 自启服务；
- **定时治理**：每日 04:00 CST 自动执行空间治理、无主附件清理与全量冷备归档；
- **统一密码**：内网所有服务登录密码遵循维护者约定统一为 `<统一口令>`。
