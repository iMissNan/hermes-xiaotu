# 📥 00-Inbox (临时收件箱)

此目录是知识库的**“暂存中转站”**。面向维护者日常随手记事、未定稿灵感或外部网页快速剪藏。

## 规则与生命周期
1. **随意录入**：维护者可以在此自由新建笔记、记录想法，无需担心格式不规范；
2. **定期归类**：当想法成熟或排障完成，由 Hermes Agent 协助提炼并流转至 `01-Notes` 或 `02-Projects`；
3. **防膨胀清理**：
   - 超过 **7 天** 无修改动作：Agent 在每周巡检报告中提醒梳理；
   - 超过 **30 天** 仍未处理且无价值便签：自动移动至 `_trash/` 回收站，防止历史垃圾堵塞第二大脑。
