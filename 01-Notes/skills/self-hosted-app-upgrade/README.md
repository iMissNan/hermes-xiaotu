## 核心使用方式

1. **单应用/别名升级**：输入 `creditdaddy 升级`、`10r 升级`、`积分管家 检查更新`、`clash 升级`
2. **多应用拓扑串行升级**：输入 `creditdaddy, 10router 升级` 或 `cd 和 10r 一起升`
3. **版本一致秒回**：若上游无更新，系统在 Stage 1 输出 1 秒绿灯回执并熔断，防止空转与焦虑
4. **全盘自检**：输入 `版本雷达` 或 `自托管更新巡检`
