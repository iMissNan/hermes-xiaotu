# 🎬 云影院与家庭多媒体系统运维规范

> **摘要**：记录家庭多媒体生态（Mars TV 云影院、TVBox 蜘蛛抓取源、YesPlayMusic 听歌中心）的业务架构、音质体验保障与播放跳歌避坑指南。

---

## 1. 业务全景与服务分工

```
[家庭娱乐设备]
       ├── 电视机 / 移动端 ──> 影视仓 App (配置专用 TVBox 蜘蛛接口)
       ├── 个人电脑浏览器 ───> Mars TV 云影院网页站 (:8082 / :8090)
       └── 桌面/音箱 ────────> YesPlayMusic 音乐中心 (:8660) + Lyricify 桌面歌词
```

- **影视双方案并行**：
  - 手机/电视端走影视仓（TVBox 爬虫聚合源）；
  - 电脑端直开网页云影院（海报墙 + 智能搜索 + 点开即播）；
  - **彻底弃用 Jellyfin**（使用门槛高、刮削繁琐）。

---

## 2. 核心避坑实录与音画质铁律

### (1) 🎵 音乐体验铁律（2026-09-03 确立）
- **铁律**：点开即播，**严禁连续跳歌**！体验永远大于代码工程的极简；
- **排障教训**：用户机器 `lqdn9sp` 曾安装 Clash Verge (`:7897`) 并在浏览器残留了 Proxy 插件，强行代理导致 YPM 本地连接断流引发跳歌，清理插件后即刻恢复正常；
- **曲库品质**：拒绝口水歌、劣质 AI 编曲与刷榜歌，专注汽水音乐/抖音热歌流行精品。

### (2) 🎬 Mars TV 云影院前后端联动规范
- **端口**：前端静态站点 `:8082`，后端 Python API `:8090`，蜘蛛采集 `:8095`；
- **修改约束**：每次改动前端 HTML/JS 或后端 Python 后，必须使用真实浏览器或 curl 进行全量链路验证；
- **Spider 协议与苹果 CMS 源**：社区常见的 TVBox 接口（如肥猫、摸鱼）与标准苹果 CMS VOD 源协议不同，必须由蜘蛛层转译，严禁直连。

## 3. 极简健康巡检命令

```bash
# 检查 YesPlayMusic 容器健康
docker ps --filter "name=yesplaymusic"

# 检查 Mars TV 后端与蜘蛛服务
systemctl status martv-backend.service martv-spider.service

# 查看每日音乐健康检查日志
cat ~/.local/opt/yesplaymusic/health-check.log | tail -n 10
```
