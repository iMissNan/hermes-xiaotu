# 📝 01-Notes (常青知识与排障实录)

此目录存放经过整理、沉淀的**技术原理、通用排障实录与长期经验**。

## 规则与生命周期
1. **真实铁证支撑**：每篇排障实录必须包含“现象、底层根因、实测修复、长期防坑”四大要素；
2. **同类经验合并**：遇到同类技术点（如“Docker 端口映射陷阱”），在既有卡片内追加章节，绝不重复开卡；
3. **长期保留**：知识经验不设过期时间，只要技术栈仍在使用，永久存续。
