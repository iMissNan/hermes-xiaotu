# 0-基础环境

> 一句话：一切的地基——Ubuntu 系统初始化、Docker 运行时、Git 仓库与钩子防线。后续所有指南都假设本章已完成。

## 1. 是什么

家庭服务器所有服务的公共底座：操作系统调优（内存/日志/时区）、Docker（8 个服务容器运行于此）、Git（配置版本化 + 部署钩子防线）。本章还启用了**用户级 systemd**（`lingering`），让不开机登录也能常驻用户服务。

## 2. 上游原址

- Docker Engine：https://docs.docker.com/engine/install/ubuntu/ （官方 apt 源，CE 版）
- Git：Ubuntu 官方仓库
- 参考硬件：x86_64 双核级 CPU / 8G+ 内存 / 120G+ SSD（本仓维护者实际运行于 16G 内存环境）

## 3. 部署

### 3.1 系统初始化

```bash
# 时区与时间同步（全系统统一 Asia/Shanghai）
sudo timedatectl set-timezone Asia/Shanghai
sudo timedatectl set-ntp true

# 内存策略：低 swap 倾向（服务常驻，避免莫明换页卡顿）
echo 'vm.swappiness=10' | sudo tee /etc/sysctl.d/90-swap.conf
sudo sysctl --system

# journald 限制日志体积（防塞盘）
sudo mkdir -p /etc/systemd/journald.conf.d
printf '[Journal]\nSystemMaxUse=500M\n' | sudo tee /etc/systemd/journald.conf.d/size.conf
sudo systemctl restart systemd-journald

# 精简无用桌面服务（服务器场景）
sudo systemctl disable --now ModemManager multipathd fwupd 2>/dev/null || true
```

### 3.2 Docker 安装

```bash
# 官方源安装（版本随官方最新 stable）
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER   # 重新登录生效
```

**守护进程配置**（日志轮转 + live-restore，防日志塞盘、升级不掉容器）——`/etc/docker/daemon.json`：

```json
{
  "log-driver": "json-file",
  "log-opts": { "max-size": "10m", "max-file": "3" },
  "live-restore": true
}
```

```bash
sudo systemctl restart docker
docker info | grep -E 'Logging|Live'   # 确认生效
```

### 3.3 Git + 本仓 + 钩子防线

```bash
sudo apt install -y git
git config --global user.name "<你的名字>"
git config --global user.email "<你的邮箱>"

# 克隆本仓（含 hooks/ 目录），并启用仓库级钩子
git clone <本仓地址> ~/vault
cd ~/vault
git config core.hooksPath hooks
# 钩子包含：commit-msg（中文 Conventional Commits 校验）+ pre-push（敏感真值扫描）
```

### 3.4 用户级服务常驻（关键）

```bash
# 允许用户级 systemd 单元开机自启（无需登录）
sudo loginctl enable-linger $USER
loginctl show-user $USER | grep Linger   # 应为 Linger=yes
```

## 4. 配置

- **磁盘规划**：系统盘 120G+ SSD；Docker 数据默认 `/var/lib/docker`；各服务数据卷统一放各自家目录（见各指南）。
- **安全基线**：SSH 密钥登录、UFW 默认拒绝、放行内网网段 `<内网网段>`（文档示例：192.168.10.0/24，按你自己的网段填）与 Tailscale 网段；对公网只暴露必要入口（见第 1 章）。
- 统一口令约定：内网自托管服务登录密码统一为复刻者自设的 `<统一口令>`（明文只存本地台账，见第 10 章 Vaultwarden）。

## 5. 数据重建

本章无可迁移数据。复刻者在此章建立的是自己的**初始身份**：Git 用户、Docker 环境、钩子防线。

## 6. 服务联动

- 0 → 一切：所有容器跑在 Docker 上，所有 Git 化配置走本仓钩子。
- 磁盘健康：建议加装 `smartmontools`（`sudo apt install smartmontools`）定期 `smartctl -H /dev/sda` 巡检。

## 7. 验证

```bash
docker run --rm hello-world          # Docker 可用
git -C ~/vault hooks/commit-msg x    # 钩子在位（报格式错误即正常）
loginctl show-user $USER | grep Linger=yes
```

## 8. 升级与回滚

- Docker 升级：`sudo apt update && sudo apt install --only-upgrade docker-ce`（live-restore 保证容器不中断）。
- 系统调优均有独立配置文件，改坏删文件重启对应服务即回滚。
