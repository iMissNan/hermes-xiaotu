# 12-AO多智能体工作流

> 一句话：给 Agent 装上流水线——多智能体编排引擎（规划→实施→审计），附运行大盘与交接面板，把"聊着干活"升级成"按图纸施工"。

## 1. 是什么

agency-orchestrator（ao）把一个开发/研究任务拆成多角色流水线（规划 agent → 实施 agent → 审计 agent），以 Hermes CLI 为执行引擎。本机配套：运行大盘（:20132，web 界面看阶段进度）、交接面板（:20133，agent 干活进度实时可视）。

## 2. 上游原址

- ao：npm 全局包 `agency-orchestrator`（https://www.npmjs.com/package/agency-orchestrator ，以 npm 实际包名为准）
- 大盘：ao 包内置 web/server.js
- 交接面板：**自研组件**，源码随本仓 → `assets/`（handover-board 相关，部署见 3.3）
- 执行引擎：第 3 章 Hermes（`hermes-cli`）

## 3. 部署

### 3.1 ao 本体 + 大盘

```bash
npm install -g agency-orchestrator    # Node23 运行时（第 3 章已装）
ao --version
```

系统级单元 `/etc/systemd/system/ao-web.service`：

```ini
[Unit]
Description=AO orchestration dashboard
After=network.target

[Service]
User=<你的用户>
WorkingDirectory=/home/<你>
Environment=PORT=20132
Environment=HOST=0.0.0.0
Environment=PATH=/home/<你>/.npm-global/bin:/home/<你>/.local/bin:/home/<你>/.local/opt/node23/bin:/usr/local/bin:/usr/bin:/bin
Environment=AO_OUTPUT_DIR=/home/<你>/.hermes/workspace/ao-output
Environment=AO_WORKFLOWS_DIR=/home/<你>/.hermes/workspace/workflows
Environment=AO_AGENTS_DIR=/home/<你>/agency-agents-zh
Environment=AO_MODEL=<你的实施模型组合名>
Environment=AO_PROVIDER=hermes-cli
ExecStart=/home/<你>/.local/opt/node23/bin/node /home/<你>/.npm-global/lib/node_modules/agency-orchestrator/web/server.js
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now ao-web
```

### 3.2 运行纪律（踩坑换来的铁律）

1. 必须 `ao compose`（规划）→ `ao run`（执行），禁裸跑；
2. `ao run` 带 `--session-id` 且启动前查重（防重复流水线）；
3. YAML 工作流显式写 `llm.model`，启动显式 `--model`，30 秒内 `ps` 核对实际生效模型（防模型劫持）；
4. 同一任务在 AO 与"主脑直接干"之间二选一，禁双跑双审。

### 3.3 交接面板（自研，可选）

```bash
mkdir -p ~/.local/bin && cp assets/ao-handover/* ~/.local/bin/ 2>/dev/null || true
# 用户级单元（源码与单元文件随 assets/ao-handover/ 入仓，装完 enable 即可）
systemctl --user enable --now ao-handover-board
```

面板监听 :20133 只读展示 agent 交接进度；数据源为 ao 侧边车数据库（零侵入 ao 本体）。

## 4. 配置

- 模型分层：规划/验收用强模型组合，实施用耐磨便宜组合（环境变量分层指定）；
- 工作流模板：`~/.hermes/workspace/workflows/`（YAML，含验证器 `verify_llm` 用法）。

## 5. 数据重建

- 工作流产物目录 `ao-output/` 空目录起步；
- 中文 agent 人设包：从本仓相关笔记按需重建（`agency-agents-zh`）。

## 6. 服务联动

- 依赖：3（hermes-cli 引擎）、2（模型流量）、0（node）；
- 被依赖：无（最顶层消费者）；
- 大盘只读监控，崩溃不影响流水线本体。

## 7. 验证

```bash
ao --version
systemctl is-active ao-web
curl -sI http://<内网IP>:20132 | head -1        # 大盘门通
# 功能验证：跑一条最小 compose+run（如"让规划agent列3条待办"）→ 大盘见进度 → 产物落 ao-output/
```

## 8. 升级与回滚

```bash
npm install -g agency-orchestrator@latest
sudo systemctl restart ao-web
```

- 升级后跑第 7 节功能验证（引擎行为最易变）；
- 回滚 = `npm install -g agency-orchestrator@<旧版本>`。
