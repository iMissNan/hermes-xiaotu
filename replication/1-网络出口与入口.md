# 1-网络出口与入口

> 一句话：给全系统装上"血管"和"大门"——sing-box 出口分流（AI 流量/普通流量各走各路）、Tailscale 异地组网、域名 + HTTPS 统一入口。

## 1. 是什么

三件事：
- **出口（sing-box）**：所有需要出墙的流量（AI API、GitHub、影视采集）经本地代理端口出去，且**分流**——AI 专用流量走稳定直连线路，普通流量走机场线路（烧错线路=烧钱/被封，这是铁律）；
- **组网（Tailscale）**：人在外面时通过 Tailscale 虚拟网回到家里这套系统；
- **入口（monpanel）**：域名 + Let's Encrypt 证书的 HTTPS 统一门面，8443 是正式门，8444 自动跳转。

## 2. 上游原址

- sing-box：https://github.com/SagerNet/sing-box （GPL-3.0，发布页下载单二进制）
- Tailscale：https://tailscale.com/download （官方 apt 源）
- monpanel：**自研组件**，源码已随本仓发布 → `assets/monpanel/`（见第 3 节部署）

## 3. 部署

### 3.1 sing-box 出口

```bash
# 二进制安装（版本 >= 1.9）
bash <(curl -fsSL https://sing-box.app/deb-install.sh)
# 或去 GitHub Releases 下载对应架构 deb 包安装
```

配置文件 `/home/<你>/singbox/sing-box.json`，**结构模板**（节点真值请填你自己的机场/服务器）：

```json
{
  "inbounds": [
    { "type": "mixed", "tag": "ai-in",  "listen": "0.0.0.0", "listen_port": 7892 },
    { "type": "mixed", "tag": "gen-in", "listen": "0.0.0.0", "listen_port": 7894 }
  ],
  "outbounds": [
    { "type": "selector", "tag": "ai-out",  "outbounds": ["<出口服务器>"] },
    { "type": "selector", "tag": "proxy",   "outbounds": ["<机场A节点>", "<机场B节点>", "urltest-auto"] },
    { "type": "hysteria2", "tag": "<出口服务器>", "server": "<出口服务器地址>", "server_port": 443,
      "password": "<出口密码>" },
    { "type": "vless", "tag": "<机场A节点>", "server": "<机场A地址>", "server_port": 443, "uuid": "<UUID>" },
    { "type": "urltest", "tag": "urltest-auto", "outbounds": ["<机场A节点>", "<机场B节点>"] }
  ],
  "route": { "rules": [
    { "inbound": ["ai-in"], "outbound": "ai-out" },
    { "inbound": ["gen-in"], "outbound": "proxy" }
  ] }
}
```

> ⚠️ **协议注意**：直连服务器出口用 `type: hysteria2`——若误写成 vless 会出现"能用但握手动辄超时"的怪病。AI 流量（10Router 的 7892）只准走 `ai-out` 稳定线路；下载/采集/普通浏览走 `proxy`。

systemd 单元 `/etc/systemd/system/sing-box.service`：

```ini
[Unit]
Description=sing-box proxy service
After=network-online.target

[Service]
User=<你的用户>
WorkingDirectory=/home/<你>/singbox
ExecStart=/usr/local/bin/sing-box run -c /home/<你>/singbox/sing-box.json
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now sing-box
```

### 3.2 Tailscale 异地组网

```bash
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
# 浏览器登录自己的 Tailscale 账号，控制台开启 MagicDNS
tailscale status   # 拿到本机 Tailscale IP = <Tailscale IP>
```

外部访问统一走 `http://<你的机器名>.<你的tailnet名>.ts.net:<端口>`。

### 3.3 monpanel 统一 HTTPS 入口（自研）

前置：域名 `<你的域名>` 解析到家庭宽带公网 IP（DDNS 按动态更新），Let's Encrypt 证书（`certbot certonly --standalone` 或 DNS 验证均可，证书续期挂 cron）。

源码入位（本仓 `assets/monpanel/`）：

```bash
mkdir -p ~/monpanel && cp -r assets/monpanel/* ~/monpanel/
python3 -m venv ~/monpanel/.venv
~/monpanel/.venv/bin/pip install fastapi uvicorn
mkdir -p ~/monpanel/certs
cp /etc/letsencrypt/live/<你的域名>/privkey.pem ~/monpanel/certs/le-key.pem
cp /etc/letsencrypt/live/<你的域名>/fullchain.pem ~/monpanel/certs/le-cert.pem
```

两个用户级单元（`~/.config/systemd/user/`）：

```ini
# monpanel.service —— HTTPS 8443 主门
[Unit]
Description=monpanel local monitor panel
After=network.target

[Service]
WorkingDirectory=%h/monpanel
ExecStart=%h/monpanel/.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8443 --ssl-keyfile %h/monpanel/certs/le-key.pem --ssl-certfile %h/monpanel/certs/le-cert.pem
Restart=on-failure

[Install]
WantedBy=default.target
```

```ini
# monpanel-http.service —— 8444 HTTP 自动跳 HTTPS
[Unit]
Description=monpanel HTTP 8444 -> HTTPS 8443 redirector
After=network.target

[Service]
ExecStart=/usr/bin/python3 %h/monpanel/http-redirect.py
Restart=on-failure

[Install]
WantedBy=default.target
```

```bash
systemctl --user daemon-reload
systemctl --user enable --now monpanel.service monpanel-http.service
```

证书续期 cron（`crontab -e`）：

```cron
# 每月 1 日尝试续期并同步到 monpanel（按你的 certbot 方式调整）
0 4 1 * * certbot renew --quiet && cp /etc/letsencrypt/live/<你的域名>/*.pem ~/monpanel/certs/ && systemctl --user restart monpanel.service
```

## 4. 配置

- **分流纪律**（本仓运维铁律，复刻者照做少踩坑）：AI 网关（第 2 章 10Router 的 `GOOGLE_TOKEN_PROXY`）只指 `7892`；Git 推送/日常走 `7894`；**7892 与 7894 的线路用途不可混用**。
- 代理客户端（若复刻者用 Windows/Linux 桌面机）：接入 `http://<内网IP>:7894` 作为系统代理即可共享出口。

## 5. 数据重建

- sing-box 节点：填复刻者自己购买的机场订阅/自建服务器参数；
- Tailscale：登录自己的账号；
- 域名与证书：复刻者自己的域名，走自己的 DNS 服务商。

## 6. 服务联动

- 1 → 2/7/8/9/12：一切要出外网的服务，代理环境变量都指 `7892` 或 `7894`；
- 1 → 全体远程访问：Tailscale 网段即"外网形态的内网"；
- monpanel 是第 13 章验收的第一道门。

## 7. 验证

```bash
curl -x http://127.0.0.1:7892 -sI https://www.google.com | head -1    # AI 线路通
curl -x http://127.0.0.1:7894 -sI https://www.github.com | head -1    # 普通线路通
tailscale status | head -3                                            # 组网在位
curl -skI https://<你的域名>:8443 | head -1                           # HTTPS 门通
```

## 8. 升级与回滚

- sing-box 升级：换二进制 + `systemctl restart sing-box`；配置文件改前 `cp sing-box.json sing-box.json.bak`；
- Tailscale：官方源随系统升级；
- monpanel：代码在仓里，`git pull` 后重启用户级单元；证书过期是最常见故障，看 8444 是否还能跳转即可初判。
